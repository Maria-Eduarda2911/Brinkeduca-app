Este projeto foi migrado de Android Nativo para **React Native com Expo**.

## 🚀 Como Rodar no VS Code

1. Abra a pasta do projeto no VS Code.
2. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o Expo:
   ```bash
   npx expo start
   ```
5. Use o app **Expo Go** no seu celular para escanear o QR Code.

## 🏗️ Estrutura Atual
- `App.tsx`: Componente principal com a lógica de questões.
- `app.json`: Configurações do Expo e Android.
- `package.json`: Lista de dependências.
- `tsconfig.json`: Configuração do TypeScript.

---
**Nota**: Os arquivos da versão Android Nativa (Kotlin) ainda estão nas pastas `app/src/main/java...`, você pode mantê-los como referência ou apagá-los futuramente.
